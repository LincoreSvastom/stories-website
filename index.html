How it works

Three steps. A clear handoff.

Bring your own media

Choose footage you own or are authorized to use. Set duration, layout, background and encoding quality. Processing runs locally with FFmpeg.

Review the result

Preview the output, adjust the framing, and inspect episode names and metadata. Original source files are not replaced by the editor.

Choose the destination

Authorize an account and select an eligible platform workflow. Confirm the queue or upload yourself. TikTok Inbox requires completion inside TikTok.

TikTok

Eligibility and review required

Desktop Login Kit and Content Posting API integration is under preparation. Inbox upload and Direct Post are distinct workflows with different permissions and completion steps.

  • Inbox: review and finish posting in TikTok
  • Direct Post: approved access and eligible account required
  • Public Direct Post is not verified for Stories
TikTok posting requirements ↗
Stories is not represented as TikTok-approved. The current desktop integration still needs platform-required posting UX and review work before it can be described as ready for public Direct Post.
